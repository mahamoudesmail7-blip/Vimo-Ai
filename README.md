# Vimo AI

Vimo AI is an AI-powered platform that transforms product images into professional advertising videos using AI video generation, Egyptian Arabic voiceovers, and automated creative production.

العميل بيرفع صورة المنتج ووصف قصير، وبياخد فيديو إعلاني 24 ثانية بصوت وكلام بالعامية المصرية، جاهز لتيك توك وريلز وفيسبوك. البيع بالفيديو: العميل بيشتري باقة، يحوّل فودافون كاش، والأدمن بيأكد التحويل فالرصيد يتضاف.

## إزاي الفيديو بيتعمل

1. **السكريبت:** نموذج ذكاء اصطناعي بيشوف صورة المنتج الأول ويفهم هو إيه وبيتمسك ويتستخدم إزاي وشكله بالظبط، وبعدين يكتب 3 مشاهد: Hook يوقف الاسكرول، فايدة حقيقية، وعرض ودعوة للشراء. كل مشهد فيه جملة مصرية مدتها حوالي 8 ثواني. بيشتغل على fal بنفس `FAL_KEY` (النموذج من `VIMO_SCRIPT_MODEL`، الافتراضي Claude Sonnet 4.5)، أو OpenAI لو `OPENAI_API_KEY` موجود. لو فشل، بيتكتب سكريبت من قالب ثابت.
2. **صورة البداية:** لكل مشهد، Nano Banana Pro (`VIMO_KEYFRAME_MODEL`) بيحط صورة المنتج نفسها في مشهد واقعي (شخص مصري، بيت حقيقي، المنتج في إيده بالطريقة الصح) من غير ما يغير شكله. لو فشلت، المشهد بيبدأ من صورة المنتج الأصلية.
3. **المشاهد:** كل مشهد بيتحرك من صورة البداية بـ Veo 3.1 Fast على fal (فيديو بصوت وكلام)، مع تعليمات إن المنتج ميتغيرش وقائمة بالحاجات الممنوعة (تشوه، تغيير لون أو لوجو، كتابة على الشاشة).
4. **الدمج:** المشاهد التلاتة بتتجمع في فيديو واحد 24 ثانية بـ `ffmpeg-api/merge-videos` على fal.
5. **الحفظ:** الفيديو النهائي بيتنسخ في قاعدة البيانات عندنا (روابط fal مؤقتة).

قبل ما يدفع، العميل يقدر يضغط «شوف السكريبت الأول» ويقرا الكلام اللي هيتقال ويعدّله، وده مجاني (بحد 30 مرة في الساعة). ولو الفيديو طلع مش عاجبه، «اعمله تاني» بيعمل فيديو جديد بنفس الصورة والسكريبت ويخصم فيديو.

كل ده بيشتغل في الخلفية (worker كل 6 ثواني)، فالعميل يقدر يقفل الصفحة ويرجع يلاقي الفيديو. لو أي مشهد فشل بيتعاد مرة، ولو فشل تاني الفيديو بيتلغي والرصيد بيرجع للعميل تلقائي.

## التشغيل

محتاج Node 20 أو أحدث وقاعدة بيانات PostgreSQL.

```bash
cp .env.example .env        # واملا DATABASE_URL و JWT_SECRET و FAL_KEY
npm install
npx prisma migrate deploy
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='كلمة-سر-قوية' ADMIN_NAME='Mahmoud' npm run admin:create
npm run dev                 # http://localhost:3000
```

### الرفع على Railway

1. New Project ثم Deploy from GitHub repo واختار الريبو ده، وضيف PostgreSQL للمشروع.
2. في Variables ضيف `DATABASE_URL` (من خدمة Postgres) و `JWT_SECRET` و `FAL_KEY` و `OPENAI_API_KEY` و `VODAFONE_CASH_NUMBER`.
3. `railway.json` فيه أمر التشغيل (`npm start`، اللي بيعمل `prisma migrate deploy` الأول) وفحص `/health`.
4. حط إيميلك في `ADMIN_EMAILS` وسجّل بيه من صفحة «إنشاء حساب»، والحساب هيبقى أدمن لوحده. (أو `npm run admin:create`.)
5. نسيت باسورد الأدمن؟ ضيف `ADMIN_RESET_PASSWORD` بالباسورد الجديد في Variables، واستنى الـ Deploy، وادخل بيه، وبعدين امسح المتغير.

## الإعدادات المهمة

كل الإعدادات في `.env.example`. أهمها:

- `VODAFONE_CASH_NUMBER`: الرقم اللي العملاء بيحوّلوا عليه (الافتراضي 01113878767).
- `FAL_KEY`: المزود الأساسي. `HIGGSFIELD_API_KEY` + `HIGGSFIELD_API_SECRET` و `GOOGLE_SERVICE_ACCOUNT_JSON` بيضيفوا Higgsfield وجوجل. المفاتيح بتتحط في متغيرات البيئة بس.
- `VIMO_PACKAGES`: الباقات والأسعار (JSON). الافتراضي زي EasyVideos: فيديو بـ 350، 3 بـ 800، 5 بـ 1200، 10 بـ 2000.
- `VIMO_VIDEO_MODEL`: نموذج الفيديو على fal (الافتراضي `fal-ai/veo3.1/fast/image-to-video`). `fal-ai/veo3.1/image-to-video` جودة أعلى وأغلى.
- `VIMO_VIDEO_MODE=ingredients`: زي «Ingredients» في Google Flow. بدل ما المشهد يتحرك من صورة البداية، Veo 3.1 Reference-to-Video بيعمله من صورة البداية وصورة المنتج كمراجع ثابتة. نفس السعر.
- `VIMO_KEYFRAME_MODEL`: نموذج صورة البداية (الافتراضي `fal-ai/nano-banana-pro/edit`)، و`off` يلغيها.
- `VIMO_SCRIPT_MODEL`: نموذج كتابة السكريبت على fal (الافتراضي `anthropic/claude-sonnet-4.5`).
- `VIMO_CLIP_COUNT` و `VIMO_CLIP_SECONDS`: عدد المشاهد وطول كل واحد (3 × 8 = 24 ثانية).

## محركات الذكاء الاصطناعي

الفيديو بيتعمل من أكتر من مزود، والأدمن بيتحكم فيهم من صفحة **«محركات الذكاء الاصطناعي»** في لوحة الأدمن. العميل مش بيشوف أسماء مزودين ولا موديلات.

- **المزودين:** fal.ai (Veo 3.1 Lite/Fast/Full، صورة البداية، التعليق الصوتي، الدمج)، Higgsfield API الرسمي (Kling 2.5 Turbo و Hailuo 2.3، فيديو صامت)، و Google Vertex AI Veo 3.1 (الطريق الرسمي لـ Veo عند جوجل؛ Google Flow مالوش API). وفيه محرك تجريبي مجاني للتطوير.
- **الاختيار:** الأدمن بيختار فئة الجودة (اقتصادي / قياسي / ممتاز)، والنظام بياخد أرخص موديل مناسب جوه الفئة دي (الأولوية بتفصل لو السعر واحد). الخطة بتتثبت على الفيديو وقت الطلب، ومفيش تحويل لمزود أغلى لوحده: لو المحرك المختار مش متاح، الطلب بيترفض من غير ما يتخصم من العميل.
- **طرق الإنتاج:** «الكلام جوه الفيديو» (الشخص بيتكلم وشفايفه ماشية مع الكلام)، أو «فيديو صامت + تعليق صوتي» وده أرخص. «تلقائي» بياخد الأرخص، و«عرض المنتج» دايمًا تعليق صوتي.
- **التكلفة:** قبل أي فيديو بنحسب تكلفته المتوقعة ونتأكد إنها جوه حد الفيديو الواحد والحد اليومي (الكلي ولكل مزود) وإن فيه **رصيد مؤكد** عند المزود: fal بيقرا رصيده لوحده لو المفتاح يسمح، وغير كده الأدمن يكتب الرصيد اللي شحنه. كل خطوة بتتسجل تكلفتها، والفيديو اللي يفشل بيرجّع الرصيد للعميل. الضغطة المكررة على «إنشاء الفيديو» بتعمل فيديو واحد بخصم واحد.

## التكلفة

Veo 3.1 Fast بالصوت على fal سعره 0.15 دولار للثانية (3.6 دولار للـ 24 ثانية)، وصور البداية 0.15 دولار للصورة (0.45 للتلاتة)، والسكريبت سنتات. يعني الفيديو بيتكلف حوالي 4.1 دولار. راجع [أسعار fal](https://fal.ai/pricing) قبل ما تحدد أسعارك، وظبط `VIMO_COST_PER_SECOND_USD` عشان لوحة الأدمن تحسب صح.

## الاختبارات

```bash
npm test                                         # اختبارات السكريبت والبرومبت
TEST_DATABASE_URL=postgresql://... npm test      # + اختبار كامل: تسجيل، شحن، تأكيد، فيديو، تحميل، ورجوع الرصيد لو فشل
```

الاختبار الكامل بيستخدم fal وهمي، فمبيصرفش أي فلوس. استخدم قاعدة بيانات فاضية للاختبار بس، لأنه بيمسح الجداول.
